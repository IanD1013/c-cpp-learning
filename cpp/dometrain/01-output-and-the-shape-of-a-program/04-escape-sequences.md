# C++ 字符串中的转义序列（Escape Sequence）

在 C++ 中，我们经常使用字符串字面量：

```cpp
std::cout << "Hello";
```

字符串由双引号 `"` 包围。

但有些特殊字符不能直接、可靠地写在字符串中，例如：

* 双引号 `"`
* 制表符 Tab
* 反斜杠 `\`
* 换行符

这时需要使用 **转义序列（escape sequence）**。

---

## 1. 什么是转义序列？

转义序列通常由：

```text
\ + 一个字符
```

组成。

例如：

```cpp
\"
\t
\\
\n
```

虽然源码中看起来是两个字符，但编译器会把它们解释为 **一个特殊字符**。

例如：

```cpp
std::cout << "Hello\nWorld";
```

这里的：

```cpp
\n
```

不是两个普通字符：

```text
\
n
```

而是一个：

```text
newline（换行字符）
```

因此输出为：

```text
Hello
World
```

---

# 2. `\"`：在字符串中表示双引号

双引号 `"` 本身有特殊作用：它用于开始和结束字符串。

例如：

```cpp
std::cout << "hello";
```

两个 `"` 定义了字符串的边界。

所以，如果直接在字符串内部写双引号：

```cpp
std::cout << "she said "stop"";
```

编译器会认为：

```cpp
"she said "
```

这里字符串已经结束。

后面的：

```cpp
stop
```

就不再属于字符串，因此会产生语法错误。

---

## 正确方法：使用 `\"`

如果希望双引号作为字符串内容的一部分，就使用：

```cpp
\"
```

例如：

```cpp
std::cout << "she said \"stop\"";
```

输出：

```text
she said "stop"
```

这里：

```cpp
\"
```

表示：

> 这个 `"` 是普通字符，不是字符串结束标记。

需要注意：

```text
\
```

不会被打印出来。

源码：

```cpp
\"stop\"
```

最终输出只是：

```text
"stop"
```

---

# 3. `\t`：Tab 制表符

`\t` 表示 **水平制表符（horizontal tab）**：

```cpp
std::cout << "one\ttwo";
```

输出大致看起来像：

```text
one     two
```

中间的空隙不是普通空格，而是一个真正的 **Tab 字符**。

---

## Tab 和空格并不相同

下面两个字符串看起来可能很像：

```cpp
"one\ttwo"
```

和：

```cpp
"one    two"
```

但是它们内部完全不同。

第一个包含：

```text
one + Tab + two
```

第二个包含：

```text
one + 若干空格 + two
```

如果自动测试进行严格字符串比较：

```text
expected == actual
```

那么：

```cpp
"one\ttwo"
```

和：

```cpp
"one    two"
```

不会被认为相等。

---

# 4. 为什么最好使用 `\t`，而不是直接输入 Tab？

理论上，在字符串中直接按 Tab 键有时也是合法的。

例如编辑器里可能出现：

```cpp
"one	two"
```

但是这样不推荐，因为：

1. Tab 看起来和多个空格非常相似。
2. 某些编辑器会自动把 Tab 转换为空格。
3. 别人很难判断这里究竟是 Tab 还是空格。
4. 自动测试可能要求真正的 Tab 字符。

所以推荐明确写成：

```cpp
"one\ttwo"
```

这样代码的含义非常清楚。

---

# 5. `\\`：表示反斜杠

反斜杠：

```text
\
```

本身在 C++ 字符串里具有特殊意义。

因为它表示：

> 后面的字符需要进行特殊解释。

例如：

```cpp
\n
```

表示换行。

```cpp
\t
```

表示 Tab。

所以如果真的想输出一个反斜杠：

```text
\
```

需要写成：

```cpp
\\
```

例如：

```cpp
std::cout << "C:\\temp";
```

输出：

```text
C:\temp
```

源码中的：

```cpp
\\
```

最终只产生一个：

```text
\
```

---

# 6. 一个很容易踩坑的例子：`C:\temp`

假设写：

```cpp
std::cout << "C:\temp";
```

你可能以为输出：

```text
C:\temp
```

但实际上：

```cpp
\t
```

会被解释为 Tab。

字符串实际上类似于：

```text
C:
Tab
emp
```

也就是说：

```cpp
"C:\temp"
```

里面的：

```cpp
\t
```

已经不再表示：

```text
\ + t
```

而是一个 Tab 字符。

因此 Windows 路径通常应该写成：

```cpp
"C:\\temp"
```

---

# 7. 为什么叫 Escape？

这里的 `\` 可以理解为：

> 让后面的字符“逃离”它原本的含义。

例如：

```cpp
"
```

本来表示：

> 结束字符串。

但是：

```cpp
\"
```

让它“逃离”这个语法意义，变成：

> 普通的双引号字符。

类似地：

```cpp
\
```

本来是 escape character。

如果希望它自己作为普通字符出现：

```cpp
\\
```

第一个 `\` 告诉编译器：

> 后面的 `\` 不再作为转义符，而是普通反斜杠。

---

# 8. 常见 C++ 转义序列

| 写法   | 表示  |
| ---- | --- |
| `\n` | 换行  |
| `\t` | Tab |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\\` | 反斜杠 |
| `\r` | 回车  |

初学阶段最重要的通常是：

```cpp
\n
\t
\"
\\
```

---

# 9. 如何阅读包含很多转义符的字符串？

例如：

```cpp
std::cout << "\"quoted\"\tback\\slash";
```

不要试图一次性看懂整个字符串。

可以拆开：

```text
\"
quoted
\"
\t
back
\\
slash
```

逐部分翻译：

```text
\"      → "
quoted  → quoted
\"      → "
\t      → Tab
back    → back
\\      → \
slash   → slash
```

最终内容就是：

```text
"quoted"    back\slash
```

注意 `"quoted"` 和 `back\slash` 之间是一个真正的 Tab，而不是若干空格。

---

# 10. `std::cout` 与 `<<`

C++ 中常见输出方式：

```cpp
std::cout << "Hello";
```

其中：

```cpp
std::cout
```

是标准输出流。

`<<` 可以理解为：

> 把右边的数据送入输出流。

例如：

```cpp
std::cout << "one" << "two";
```

输出：

```text
onetwo
```

`<<` 自己不会产生空格或换行。

---

也可以组合多个部分：

```cpp
std::cout << "\"" << "quoted" << "\"";
```

输出：

```text
"quoted"
```

不过如果内容比较简单：

```cpp
std::cout << "\"quoted\"";
```

通常更加简洁。

---

# 11. 自动测试题中要特别注意“看起来一样”和“实际上相同”

编程练习经常使用严格字符串比较。

例如要求：

```text
"quoted"	 back\slash
```

如果要求中间是 Tab，那么下面这种实现：

```cpp
std::cout << "\"quoted\"    back\\slash";
```

即使肉眼看起来很像，也可能测试失败。

因为：

```cpp
\t
```

和：

```cpp
"    "
```

不是同一个字符。

因此如果：

* 三个测试过两个；
* 只剩一个严格测试失败；

很可能问题就是：

```text
Tab / 空格 / 换行 / 多余字符
```

这种精确字符差异。

---

# 12. 核心记忆

可以把最常用的四个记成：

```cpp
\n    // newline
\t    // tab
\"    // double quote
\\    // backslash
```

并记住一个总原则：

> 在字符串中，反斜杠 `\` 会改变后一个字符的含义。

因此：

```cpp
\"  → "
\\  → \
\t  → Tab
\n  → 换行
```

源码中看到的是转义写法，真正存储和输出的是对应的字符。
