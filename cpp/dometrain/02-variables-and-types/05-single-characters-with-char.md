# C++ `char`、字符字面量与字符编码运算

## 1. `char`：用于保存单个字符

C++ 中，`char` 用来保存**一个字符**。

```cpp
char grade = 'A';
char letter = 'x';
char symbol = '!';
```

字符字面量使用**单引号 `' '`**：

```cpp
'A'
'x'
'7'
```

例如：

```cpp
char grade = 'A';
```

这里：

* `char` 是变量类型
* `grade` 是变量名
* `'A'` 是字符字面量

---

## 2. 单引号 `'A'` 和双引号 `"A"` 完全不同

这是 C++ 初学阶段非常重要的区别。

### 单引号：一个字符

```cpp
'A'
```

表示一个字符，可以保存到 `char` 中：

```cpp
char letter = 'A';
```

### 双引号：字符串

```cpp
"A"
```

表示一个字符串。

因此下面是不对的：

```cpp
char letter = "A";  // 错误
```

虽然 `"A"` 看起来也只有一个字母，但它实际上包含的是一个字符串。

更准确地说，C++ 中：

```cpp
"A"
```

本身的类型类似于：

```cpp
const char[2]
```

因为它实际上包含：

```text
'A'
'\0'
```

其中 `'\0'` 是字符串末尾的结束字符。

在很多表达式中，字符串数组又会自动转换成：

```cpp
const char*
```

所以初学时可以简单记忆：

```text
'A'   → 单个字符 → char

"A"   → 字符串
```

---

# 3. `char` 底层实际上也是一个整数

虽然我们通常把 `char` 当作字符使用，但计算机内部最终保存的仍然是一个**字符编码对应的整数值**。

例如在常见的 ASCII 编码中：

```text
'A' → 65
'B' → 66
'C' → 67

'a' → 97
'b' → 98
'c' → 99
```

因此：

```cpp
char letter = 'A';
```

可以理解成 `letter` 内部保存了 `'A'` 对应的字符编码。

不过程序正常输出这个 `char` 时：

```cpp
std::cout << letter;
```

看到的是：

```text
A
```

而不是：

```text
65
```

---

# 4. 字符之间可以进行减法

因为字符对应整数编码，所以两个 `char` 可以参与算术运算。

例如：

```cpp
'a' - 'A'
```

在 ASCII 编码中：

```text
'a' = 97
'A' = 65
```

因此：

```text
'a' - 'A'
= 97 - 65
= 32
```

也就是说：

```cpp
'a' - 'A'
```

代表了：

> 大写字母和对应小写字母之间的字符编码距离。

类似地：

```cpp
'b' - 'B'
```

也是：

```text
32
```

```cpp
'z' - 'Z'
```

也是：

```text
32
```

因此无需分别处理 26 个字母。

---

# 5. 不要死记字符编码差值 `32`

虽然在 ASCII 中：

```text
小写字母编码 - 大写字母编码 = 32
```

但代码中更推荐表达成：

```cpp
'a' - 'A'
```

而不是直接写：

```cpp
32
```

例如：

```cpp
char upper = 'H';

char lower = upper + ('a' - 'A');
```

计算过程为：

```text
'H'
+ ('a' - 'A')

= 72 + (97 - 65)

= 72 + 32

= 104
```

104 对应：

```text
'h'
```

所以：

```cpp
lower == 'h'
```

---

# 6. 大写字母转换为小写字母

如果已经知道一个字符一定是大写字母：

```cpp
char upper = 'H';
```

那么可以加上大小写字符之间的距离：

```cpp
char lower = upper + ('a' - 'A');
```

可以理解为：

```text
大写字母
    ↓
向后移动大小写之间的距离
    ↓
对应的小写字母
```

例如：

```text
'H'
+ 32
↓
'h'
```

---

# 7. 小写字母转换为大写字母

反过来，如果已经知道：

```cpp
char lower = 'h';
```

想得到：

```text
'H'
```

就应该**减去**这个距离：

```cpp
char upper = lower - ('a' - 'A');
```

计算过程：

```text
'h' = 104

'a' - 'A'
= 97 - 65
= 32

104 - 32
= 72

72 → 'H'
```

因此：

```cpp
char upper = lower - ('a' - 'A');
```

---

# 8. 为什么一个公式可以处理所有 26 个字母？

因为英文字母的字符编码是连续排列的。

例如：

```text
小写：

'a' 97
'b' 98
'c' 99
...
'z' 122
```

对应的大写：

```text
'A' 65
'B' 66
'C' 67
...
'Z' 90
```

两组字母内部的相对位置完全一致。

例如：

```text
'a' - 'A' = 32
'b' - 'B' = 32
'c' - 'C' = 32
...
'z' - 'Z' = 32
```

所以同一个公式：

```cpp
letter - ('a' - 'A')
```

可以处理：

```text
a → A
b → B
c → C
...
z → Z
```

# 9. 字符运算时，C++ 实际会先把 `char` 当整数计算

例如：

```cpp
char letter = 'h';

char upper = letter - ('a' - 'A');
```

表达式：

```cpp
letter - ('a' - 'A')
```

进行算术时，本质上是在计算整数。

也就是说，可以粗略理解成：

```text
104 - (97 - 65)
```

得到：

```text
72
```

然后结果赋值给：

```cpp
char upper
```

于是字符编码 `72` 被解释为：

```text
'H'
```

因此这里虽然代码看起来是在对“字母”做减法，底层实际上是：

```text
字符 → 编码整数 → 算术运算 → 新编码 → 字符
```

---

# 10. 本题为什么不需要 `if`

假设函数的输入保证一定是：

```text
'a' 到 'z'
```

那么：

```cpp
letter - ('a' - 'A')
```

对每一个输入都成立。

所以不需要：

```cpp
if (...)
```

也不需要：

```cpp
switch (...)
```

更不需要把 26 个字母全部列出来。

例如这种方式虽然可能得到正确结果，但完全没有必要：

```cpp
if (letter == 'a') {
    return 'A';
}

if (letter == 'b') {
    return 'B';
}
```

字符编码的规律已经为我们提供了统一公式。

---

# 11. 为什么题目不允许直接写 `32`

题目要求：

> 不允许在代码中直接出现字面量 `32`。

也就是说不能写：

```cpp
return letter - 32;
```

而应该写：

```cpp
return letter - ('a' - 'A');
```

这样做还有一个重要意义：

```cpp
'a' - 'A'
```

表达的是代码真正想表达的概念：

> 小写字母和大写字母之间的编码距离。

而：

```cpp
32
```

只是一个没有上下文的“魔法数字（magic number）”。

从可读性来看：

```cpp
letter - ('a' - 'A')
```

通常比：

```cpp
letter - 32
```

更清楚。

# 12. 本题为什么不需要 `toupper`

C/C++ 标准库本身提供了字符转换函数，例如：

```cpp
std::toupper(...)
```

实际项目中，通常应该优先使用标准库，而不是自己依赖字符编码规律。

但是这道练习明确禁止使用：

```cpp
toupper
```

以及：

```cpp
std::toupper
```

原因是这道题真正想训练的并不是标准库，而是：

```text
char 本质上可以参与整数运算
+
字符编码之间存在规律
+
可以利用两个字符的差值进行字符转换
```

---

# 13. 一个非常重要的前提：输入范围已经由题目保证

题目明确告诉我们：

```text
输入一定是小写字母
```

并且字符编码范围是：

```text
97 ~ 122
```

也就是：

```text
'a' ~ 'z'
```

因此函数不需要检查：

```cpp
if (letter >= 'a' && letter <= 'z')
```

因为题目已经保证这一点。

这是编程题中非常重要的习惯：

> 先看清函数的输入契约，再决定需要处理哪些情况。

如果题目保证：

```text
letter 一定是小写字母
```

那么就不需要额外处理：

```text
'A'
'!'
'7'
'?'
```

因为这些输入根本不会出现。

# 14. 返回 `char` 时，返回的是字符

考虑：

```cpp
static char getLetter() {
    return 'A';
}
```

函数返回类型是：

```cpp
char
```

所以 grader 通常会把返回结果理解为字符：

```text
A
```

而不是字符编码：

```text
65
```

同样：

```cpp
return 'Z';
```

对应的结果就是：

```text
Z
```

# 15. 核心公式总结

## 大写 → 小写

```cpp
lower = upper + ('a' - 'A');
```

记忆：

```text
大写字母的编码比较小
↓
加上距离
↓
得到小写字母
```

---

## 小写 → 大写

```cpp
upper = lower - ('a' - 'A');
```

记忆：

```text
小写字母的编码比较大
↓
减去距离
↓
得到大写字母
```

# 16. 最值得记住的知识点

```text
单引号 'A'
→ 字符字面量
→ char

双引号 "A"
→ 字符串
```

字符可以参与算术，因为：

```text
char 底层对应字符编码整数
```

字符之间的减法可以得到编码距离：

```cpp
'a' - 'A'
```

因此小写转大写可以写成：

```cpp
letter - ('a' - 'A')
```

而大写转小写可以写成：

```cpp
letter + ('a' - 'A')
```

本质都是：

```text
利用字符编码的相对位置进行转换
```
