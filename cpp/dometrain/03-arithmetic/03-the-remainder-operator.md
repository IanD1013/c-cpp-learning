# C++ `%` 取余运算符：理解整数除法中的“余数”

## 1. `%` 是什么？

在 C++ 中，`%` 叫做**取余运算符**（remainder operator）。

它表示：

> 两个整数做除法之后，没有办法完整分组的那部分剩余值。

例如：

```cpp
int total = 17;
int groupSize = 5;

int wholeGroups = total / groupSize;  // 3
int leftover = total % groupSize;     // 2
```

这里：

```text
17 = 3 × 5 + 2
```

所以：

* `17 / 5` 得到 `3`
* `17 % 5` 得到 `2`

可以把 `/` 和 `%` 看成整数除法的一对结果：

```text
/  → 有多少个完整的组
%  → 分完完整的组之后还剩多少
```

---

# 2. `/` 和 `%` 的关系

对于整数 `a` 和非零整数 `b`：

```text
a = (a / b) * b + (a % b)
```

这是理解 `%` 最重要的公式。

例如：

```cpp
17 / 5 == 3
17 % 5 == 2
```

因此：

```text
17 = 3 × 5 + 2
```

再例如：

```cpp
19 / 20 == 0
19 % 20 == 19
```

因为一个完整的 `20` 都放不进去：

```text
19 = 0 × 20 + 19
```

---

# 3. `%` 不是“百分比”

虽然 `%` 长得像百分号，但在 C++ 表达式中：

```cpp
total % 5
```

完全不是“`total` 的 5%”。

它表示：

> `total` 除以 `5` 后的余数。

例如：

```cpp
17 % 5
```

结果：

```cpp
2
```

而不是：

```text
17 的 5%
```

---

# 4. `%` 主要用于整数

`%` 的操作数必须是整数类型。

例如：

```cpp
int result = 17 % 5;
```

合法。

但是：

```cpp
double result = 17.5 % 5.0;
```

是不合法的。

编译器会报错，因为内置 `%` 不能直接用于 `double`。

如果以后确实需要计算浮点数余数，可以了解标准库中的：

```cpp
std::fmod()
```

但当前阶段只需要记住：

```text
% → 整数取余
```

---

# 5. 常见例子

## 情况一：能够整除

```cpp
10 % 5
```

因为：

```text
10 = 2 × 5 + 0
```

所以：

```cpp
10 % 5 == 0
```

因此，判断一个整数能不能被另一个整数整除时，经常写：

```cpp
value % divisor == 0
```

例如：

```cpp
12 % 3 == 0
```

说明 `12` 可以被 `3` 整除。

---

## 情况二：左边比右边小

```cpp
3 % 5
```

因为连一个完整的 `5` 都装不进去：

```text
3 = 0 × 5 + 3
```

所以：

```cpp
3 / 5 == 0
3 % 5 == 3
```

因此，当：

```text
0 <= total < groupSize
```

时：

```cpp
total % groupSize == total
```

例如：

```cpp
4 % 10 == 4
```

---

# 6. `0` 也可以参与取余

只要右边不是 `0`：

```cpp
0 % 5
```

是完全合法的。

因为：

```text
0 = 0 × 5 + 0
```

所以：

```cpp
0 % 5 == 0
```

---

# 7. 右边绝对不能是 `0`

下面的表达式是错误的：

```cpp
10 % 0
```

和：

```cpp
10 / 0
```

一样，除数不能为 `0`。

因此，如果程序无法保证除数非零，通常需要先检查。

例如：

```cpp
if (groupSize != 0) {
    int leftover = total % groupSize;
}
```

不过如果题目已经明确保证：

```text
groupSize >= 1
```

那么就不需要额外检查。

---

# 8. 负数取余：最重要的规则

C++ 中整数除法是：

> **向 0 截断（truncate toward zero）**

例如：

```cpp
-17 / 5
```

数学上的精确结果是：

```text
-3.4
```

向 `0` 截断以后得到：

```cpp
-3
```

因此：

```cpp
-17 / 5 == -3
```

接着根据：

```text
a = (a / b) * b + (a % b)
```

得到：

```text
-17 = (-3) × 5 + remainder
```

也就是：

```text
-17 = -15 + remainder
```

所以：

```text
remainder = -2
```

因此：

```cpp
-17 % 5 == -2
```

---

# 9. C++ 余数的符号

在 C++ 中：

> `a % b` 的结果如果不是 `0`，它的符号跟左操作数 `a` 一致。

例如：

```cpp
17 % 5 == 2
```

左边 `17` 是正数，所以结果是正数。

```cpp
-17 % 5 == -2
```

左边 `-17` 是负数，所以结果是负数。

甚至：

```cpp
17 % -5 == 2
```

结果仍然是：

```cpp
2
```

因为余数的符号由**左操作数**决定，而不是右操作数。

可以简单记成：

```text
余数看左边。
```

---

# 10. C++ `%` 和数学里的 modulo 不一定完全一样

这个区别以后非常重要。

很多数学教材或 Python 风格的讨论会把 `%` 称为 modulo，并希望结果始终非负。

例如 Python：

```python
-17 % 5
```

结果是：

```python
3
```

但是 C++：

```cpp
-17 % 5
```

结果是：

```cpp
-2
```

原因在于两个语言处理负数除法的规则不同。

对于当前 C++ 学习，只需要记住：

```cpp
-17 / 5 == -3
-17 % 5 == -2
```

并且始终满足：

```text
-17 = (-3) × 5 + (-2)
```

---

# 11. `%` 的常见用途

## 用途一：判断奇偶数

```cpp
value % 2
```

如果：

```cpp
value % 2 == 0
```

说明是偶数。

例如：

```cpp
10 % 2 == 0
```

如果：

```cpp
value % 2 != 0
```

说明是奇数。

例如：

```cpp
11 % 2 == 1
```

---

## 用途二：判断是否整除

```cpp
value % divisor == 0
```

例如：

```cpp
15 % 5 == 0
```

所以 `15` 可以被 `5` 整除。

---

## 用途三：周期循环

假设一周有 7 天：

```cpp
day % 7
```

可以把不断增长的数字限制在一个固定周期中。

例如：

```cpp
0 % 7 == 0
1 % 7 == 1
...
6 % 7 == 6
7 % 7 == 0
8 % 7 == 1
```

这类技巧以后在：

* 数组循环
* 环形缓冲区
* 星期计算
* 游戏循环
* 状态轮换

中非常常见。

---

## 用途四：拆分数值

例如把总秒数转换成：

```text
分钟 + 剩余秒数
```

可以写：

```cpp
int totalSeconds = 125;

int minutes = totalSeconds / 60;
int seconds = totalSeconds % 60;
```

结果：

```text
minutes = 2
seconds = 5
```

因为：

```text
125 = 2 × 60 + 5
```

这正是 `/` 与 `%` 配合使用的典型场景。

---

# 12. 本节核心总结

最值得记住的是下面几条：

```cpp
17 / 5 == 3
17 % 5 == 2
```

它们共同满足：

```text
17 = 3 × 5 + 2
```

一般形式：

```text
a = (a / b) * b + (a % b)
```

其中：

```text
/ → 完整分了多少组
% → 完整分组之后剩多少
```

另外：

```cpp
10 % 5 == 0
3 % 5 == 3
0 % 5 == 0
-17 % 5 == -2
```

C++ 中负数整数除法：

```text
向 0 截断
```

而余数：

```text
与左操作数同号
```

最后，永远不能：

```cpp
value % 0
```

因为除数不能为 `0`。
