# C++ 整数除法（Integer Division）

## 1. `int / int` 的结果仍然是 `int`

在 C++ 中，如果 `/` 两边的操作数都是 `int`，那么结果也会是 `int`。

例如：

```cpp
int a = 7 / 2;
int b = 19 / 20;
```

结果是：

```cpp
a == 3
b == 0
```

这里不会得到：

```cpp
3.5
0.95
```

因为参与除法的两个值都是整数。

可以记住：

```text
int / int -> int
```

---

## 2. 整数除法会直接丢弃小数部分

C++ 的整数除法不是“四舍五入”，而是直接丢弃小数部分。

例如：

```cpp
7 / 2
```

数学上：

```text
7 ÷ 2 = 3.5
```

但 C++ 的整数除法得到：

```cpp
3
```

也就是：

```text
3.5 -> 3
```

再比如：

```cpp
19 / 20
```

数学上：

```text
19 ÷ 20 = 0.95
```

整数除法结果却是：

```cpp
0
```

这里不是因为 `0.95` 被四舍五入成了 `0`，而是因为整数除法根本不会保留 `.95`。

---

## 3. 更准确的理解：能装下多少个“完整组”

整数除法很适合回答这样的问题：

> 一个总数里面，最多包含多少个完整的某个大小的组？

例如：

```cpp
19 / 20
```

可以理解成：

> 19 个东西，每 20 个分成一组，一共有多少个完整组？

显然：

```text
0 个完整组
```

因为连一个完整的 20 都凑不出来。

所以：

```cpp
19 / 20 == 0
```

这个结果并不是“不精确”，而是在回答“完整组数量”这个问题。

再比如：

```cpp
7 / 2
```

可以理解成：

```text
7 个东西
每 2 个一组
```

可以组成：

```text
3 个完整组
```

还剩：

```text
1 个
```

因此：

```cpp
7 / 2 == 3
```

---

## 4. 商和余数是两个不同的问题

整数除法 `/` 得到的是**商**。

例如：

```cpp
7 / 2
```

得到：

```cpp
3
```

但仅仅看到这个 `3`，你无法知道原来有没有剩余。

因为：

```cpp
7 / 2 == 3
6 / 2 == 3
```

这两个表达式的商相同，但情况并不一样：

```text
7 = 2 × 3 + 1
6 = 2 × 3 + 0
```

也就是说：

```text
7 / 2 -> 3 个完整组，剩 1
6 / 2 -> 3 个完整组，剩 0
```

如果想知道“剩多少”，应该使用另一个运算符：

```cpp
%
```

也就是**取模 / 求余运算符**。

例如：

```cpp
7 / 2   // 3
7 % 2   // 1
```

所以可以记住：

```text
/ -> 有多少个完整组
% -> 分完完整组之后还剩多少
```

---

## 5. 商和余数之间的关系

对于非负整数：

```text
被除数 = 除数 × 商 + 余数
```

例如：

```cpp
int total = 17;
int groupSize = 5;

int groups = total / groupSize;
int remainder = total % groupSize;
```

结果：

```cpp
groups == 3
remainder == 2
```

因为：

```text
17 = 5 × 3 + 2
```

---

## 6. `int` 除法和 `double` 除法不要混淆

下面两个表达式看起来很像，但结果完全不同：

```cpp
7 / 2
```

和：

```cpp
7.0 / 2
```

第一个：

```cpp
7 / 2
```

两边都是 `int`：

```text
int / int -> int
```

所以：

```cpp
7 / 2 == 3
```

第二个：

```cpp
7.0 / 2
```

其中 `7.0` 是 `double`，因此会进行浮点数除法：

```cpp
7.0 / 2 == 3.5
```

也就是说：

```cpp
7 / 2      // 3
7.0 / 2    // 3.5
7 / 2.0    // 3.5
```

---

## 7. 不能先做整数除法，再指望 `double` 恢复小数

这是非常常见的错误。

例如：

```cpp
double result = 7 / 2;
```

很多初学者可能会以为：

```cpp
result == 3.5
```

实际上：

```cpp
result == 3.0
```

原因是计算顺序是：

```text
先计算 7 / 2
↓
两个操作数都是 int
↓
整数除法
↓
得到 3
↓
最后把 3 转成 double
↓
3.0
```

换句话说，小数部分在执行 `/` 的那一刻就已经丢掉了。

后面再存进 `double` 也恢复不了。

如果真的需要 `3.5`，必须让除法发生时至少有一个操作数是浮点数：

```cpp
double result = 7.0 / 2;
```

或者：

```cpp
double result = static_cast<double>(7) / 2;
```

---

## 8. “整数除法截断”与负数

在本题中：

```text
total >= 0
groupSize >= 1
```

所以只需要考虑非负数。

不过完整理解 C++ 时需要知道：

C++ 的有符号整数除法是**向 0 截断**。

例如：

```cpp
7 / 2    // 3
-7 / 2   // -3
7 / -2   // -3
```

数学上的：

```text
-7 ÷ 2 = -3.5
```

C++ 会向 `0` 截断成：

```text
-3
```

而不是向负无穷方向变成 `-4`。

---

## 9. 除数不能为 0

下面这样的整数除法是非法的：

```cpp
int x = 10 / 0;
```

整数除以 0 没有合法结果。

但做编程题时是否需要检查：

```cpp
if (groupSize == 0)
```

要看题目的输入条件。

如果题目已经保证：

```text
groupSize >= 1
```

那么通常就不应该额外处理题目明确排除的情况。

---

# 总结

C++ 整数除法最核心的规则是：

```text
int / int -> int
```

小数部分会在除法发生时直接被丢弃。

例如：

```cpp
7 / 2     // 3
19 / 20   // 0
20 / 20   // 1
21 / 20   // 1
```

可以把整数除法理解为：

> 左边的数量中，可以完整放进去多少个右边的数量。

例如：

```cpp
19 / 20
```

就是：

> 19 个东西能组成多少个 20 个一组的完整组？

答案：

```text
0
```

如果还想知道剩余多少，则使用：

```cpp
%
```

例如：

```cpp
19 / 20   // 0 个完整组
19 % 20   // 剩 19

27 / 5    // 5 个完整组
27 % 5    // 剩 2
```

最值得记住的组合是：

```cpp
quotient  = a / b;
remainder = a % b;
```

对应：

```text
a = b × quotient + remainder
```
