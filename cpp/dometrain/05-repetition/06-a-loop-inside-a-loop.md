# C++ 嵌套循环（Nested Loops）教程

## 1. 什么是嵌套循环？

一个循环的循环体中，可以再放另一个循环。

这种结构叫做：

> **嵌套循环（nested loop）**

例如：

```cpp
for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        std::cout << i << j << "\n";
    }
}
```

这里有两个 `for` 循环：

* 外层循环（outer loop）：使用变量 `i`
* 内层循环（inner loop）：使用变量 `j`

程序输出：

```text
11
12
13
21
22
23
```

一共输出 6 行。

---

# 2. 嵌套循环最重要的执行规律

理解嵌套循环，最关键的一句话是：

> **外层循环每执行一次，内层循环都会从头完整执行一遍。**

上面的代码可以理解成：

```text
i = 1
    j = 1
    j = 2
    j = 3

i = 2
    j = 1
    j = 2
    j = 3
```

所以 `(i, j)` 的组合依次是：

```text
(1, 1)
(1, 2)
(1, 3)
(2, 1)
(2, 2)
(2, 3)
```

也就是：

```text
11
12
13
21
22
23
```

# 3. 哪个变量会重新开始？

观察代码：

```cpp
for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        std::cout << i << j << "\n";
    }
}
```

## 外层变量 `i`

`i` 的初始化：

```cpp
int i = 1
```

只发生一次。

之后：

```cpp
++i
```

只会在**整个内层循环执行完毕之后**运行一次。

因此：

```text
i = 1
完整执行一次 j 循环

i = 2
完整执行一次 j 循环
```

`i` 不会因为进入内层循环而重新变成 1。

---

## 内层变量 `j`

内层循环：

```cpp
for (int j = 1; j <= 3; ++j)
```

位于外层循环的循环体中。

因此每次执行外层循环时，程序都会再次执行：

```cpp
int j = 1;
```

也就是说，`j` 每次都会重新开始。

第一次：

```text
i = 1

j = 1
j = 2
j = 3
```

第二次：

```text
i = 2

j = 1
j = 2
j = 3
```

所以可以记住：

> **内层循环的计数器通常会在每次外层循环开始新一轮时重新初始化。**

# 4. 嵌套循环的真正执行顺序

下面这段代码：

```cpp
for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        std::cout << i << j << "\n";
    }
}
```

实际执行过程可以展开成：

```text
i = 1

    j = 1
    输出 11

    j = 2
    输出 12

    j = 3
    输出 13

内层循环结束

i = 2

    j = 1
    输出 21

    j = 2
    输出 22

    j = 3
    输出 23

内层循环结束

外层循环结束
```

注意：

```cpp
++i
```

并不是在每次 `j` 增加以后执行。

而是要等：

> **整个内层循环结束**

之后才执行一次。

所以执行节奏是：

```text
外层一轮
    ↓
内层全部跑完
    ↓
外层更新
    ↓
下一轮外层
```

# 5. 嵌套循环一共执行多少次？

如果：

```cpp
for (int i = 1; i <= rows; ++i) {
    for (int j = 1; j <= cols; ++j) {
        // 某段代码
    }
}
```

假设：

```text
rows = 3
cols = 4
```

那么：

* 外层循环执行 3 次
* 每次外层循环中，内层执行 4 次

因此最里面的循环体执行：

```text
3 × 4 = 12 次
```

一般来说：

```text
总执行次数 = 外层循环次数 × 内层循环次数
```

例如：

```cpp
for (int i = 1; i <= 5; ++i) {
    for (int j = 1; j <= 10; ++j) {
        ...
    }
}
```

最内层代码会执行：

```text
5 × 10 = 50 次
```

# 6. 可以把嵌套循环想象成“行 × 列”

嵌套循环特别适合处理二维结构。

例如：

```cpp
for (int row = 1; row <= 3; ++row) {
    for (int col = 1; col <= 4; ++col) {
        std::cout << row << "," << col << "\n";
    }
}
```

可以把它理解成一个：

```text
3 行 × 4 列
```

的网格。

坐标依次是：

```text
(1,1) (1,2) (1,3) (1,4)
(2,1) (2,2) (2,3) (2,4)
(3,1) (3,2) (3,3) (3,4)
```

外层循环通常控制：

```text
row
```

内层循环通常控制：

```text
column
```

因此以后学习下面这些内容时，会大量遇到嵌套循环：

* 二维数组
* 矩阵
* 表格
* 棋盘
* 图像像素
* 九九乘法表

# 7. 嵌套循环 + 累加器

嵌套循环经常和 accumulator（累加器）一起使用。

例如：

```cpp
int total = 0;

for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        total += i * j;
    }
}
```

每一次内层循环都会执行：

```cpp
total += i * j;
```

也就是：

```cpp
total = total + i * j;
```

因此程序会依次加：

```text
1×1
1×2
1×3
2×1
2×2
2×3
```

即：

```text
1 + 2 + 3 + 2 + 4 + 6
```

最终：

```text
18
```

---

# 8. 累加器为什么一定要放在外层循环之前？

正确：

```cpp
int total = 0;

for (int i = 1; i <= rows; ++i) {
    for (int j = 1; j <= cols; ++j) {
        total += i * j;
    }
}
```

这里整个函数只有一个 `total`。

所有行、所有列的结果都会不断累加到同一个变量中。

---

错误思路：

```cpp
for (int i = 1; i <= rows; ++i) {
    int total = 0;

    for (int j = 1; j <= cols; ++j) {
        total += i * j;
    }
}
```

这里每执行一次新的 `i`：

```cpp
int total = 0;
```

都会再次执行。

于是前一行计算出来的结果就丢掉了。

所以如果想统计：

> 所有行和所有列的总结果

累加器应该放在：

```cpp
外层循环之前
```

即：

```cpp
int total = 0;
```

# 9. `rows <= 0` 或 `cols <= 0` 时会发生什么？

假设：

```cpp
int total = 0;

for (int i = 1; i <= rows; ++i) {
    ...
}
```

如果：

```text
rows = 0
```

第一次判断：

```cpp
i <= rows
```

相当于：

```cpp
1 <= 0
```

结果：

```text
false
```

所以循环一次都不会执行。

最终直接：

```cpp
return total;
```

因为：

```cpp
total = 0
```

所以返回：

```text
0
```

---

例如：

```cpp
sumOfProducts(3, -2)
```

外层循环首先有：

```text
i = 1
```

如果外层仍然满足条件，它会进入内层：

```cpp
for (int j = 1; j <= -2; ++j)
```

第一次判断就是：

```text
1 <= -2
```

结果为：

```text
false
```

所以内层循环一次都不执行。

因此：

```text
total
```

仍然是：

```text
0
```

最后返回 0。

所以这种情况下不需要额外写：

```cpp
if (rows <= 0 || cols <= 0)
```

循环条件本身已经自然处理了这种情况。

# 10. 手动追踪嵌套循环的方法

看到复杂的嵌套循环时，可以画一个表。

例如：

```cpp
int total = 0;

for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        total += i * j;
    }
}
```

可以记录：

| i | j | i × j | total |
| - | - | ----: | ----: |
| 1 | 1 |     1 |     1 |
| 1 | 2 |     2 |     3 |
| 1 | 3 |     3 |     6 |
| 2 | 1 |     2 |     8 |
| 2 | 2 |     4 |    12 |
| 2 | 3 |     6 |    18 |

最终：

```text
total = 18
```

这是学习循环时非常实用的 debugging 方法。

# 11. 常见错误

## 错误 1：以为 `i` 和 `j` 会一起增加

不是：

```text
i=1,j=1
i=2,j=2
i=3,j=3
```

实际通常是：

```text
i=1,j=1
i=1,j=2
i=1,j=3
i=2,j=1
i=2,j=2
i=2,j=3
```

因为：

> 内层循环必须完整结束，外层循环才进入下一轮。

---

## 错误 2：以为 `j` 不会重新开始

实际上：

```cpp
for (int j = 1; ...)
```

这条初始化语句位于外层循环体内部。

每次新的外层循环都会再次执行：

```cpp
int j = 1;
```

因此 `j` 会重新从 1 开始。

---

## 错误 3：把累加器放进外层循环

例如：

```cpp
for (...) {
    int total = 0;
}
```

这样每一轮外层循环都会重新清零。

如果希望统计所有循环的结果，应该：

```cpp
int total = 0;

for (...) {
    ...
}
```

# 12. 一个非常经典的例子：九九乘法表

嵌套循环非常适合生成乘法表：

```cpp
for (int i = 1; i <= 9; ++i) {
    for (int j = 1; j <= 9; ++j) {
        std::cout << i << " * " << j
                  << " = " << i * j << "\n";
    }
}
```

这里：

```text
外层循环：
i = 1 ... 9

每一个 i：

内层循环：
j = 1 ... 9
```

因此乘法运算一共执行：

```text
9 × 9 = 81 次
```

# 13. 核心总结

嵌套循环可以记住以下几个规律：

1. 一个循环里面可以再放另一个循环。

2. 外层循环每执行一轮：

```text
内层循环都会完整执行一遍
```

3. 内层计数器通常会重新初始化：

```cpp
int j = 1;
```

4. 外层计数器不会因为内层循环而重新初始化。

5. 外层循环只有在：

```text
整个内层循环结束以后
```

才会更新一次。

6. 如果：

```text
外层执行 R 次
内层每次执行 C 次
```

那么最里面的代码通常执行：

```text
R × C 次
```

7. 如果要累计所有 `(i, j)` 的结果：

```cpp
int total = 0;
```

应该放在：

```text
外层循环之前
```

8. 如果循环条件第一次检查就是 `false`：

```text
循环体执行 0 次
```

因此很多零值、负值边界情况可以自然得到结果 0。

# 14. 一句话理解嵌套循环

可以把：

```cpp
for (int i = ...) {
    for (int j = ...) {
        ...
    }
}
```

理解成：

> **对每一个 `i`，把所有可能的 `j` 都处理一遍。**

也就是：

```text
for every i:
    for every j:
        do something with i and j
```

这是以后学习二维数组、矩阵、搜索组合以及许多算法时非常重要的思维方式。
