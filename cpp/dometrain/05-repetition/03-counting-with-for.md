# C++ `for` 循环：结构、执行顺序、变量作用域与累加

## 1. `for` 循环的基本结构

C++ 中，`for` 循环通常写成：

```cpp
for (初始化; 条件; 更新) {
    循环体
}
```

例如：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

输出：

```text
012
```

一个 `for` 循环的头部包含三个部分：

```cpp
for (int i = 0; i < 3; i++)
     └──────┘  └───┘  └─┘
       初始化     条件    更新
```

---

## 2. `for` 循环真正的执行顺序

以上代码：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

实际执行顺序是：

```text
初始化
↓
检查条件
↓
执行循环体
↓
更新
↓
检查条件
↓
执行循环体
↓
更新
↓
……
```

因此可以记成：

```text
初始化一次

然后不断重复：

条件 → 循环体 → 更新 → 条件 → 循环体 → 更新 → ...
```

具体到这个例子：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

执行过程是：

```text
int i = 0

检查：0 < 3 → true
输出：0
i++ → i = 1

检查：1 < 3 → true
输出：1
i++ → i = 2

检查：2 < 3 → true
输出：2
i++ → i = 3

检查：3 < 3 → false
结束循环
```

所以：

```text
输出 0、1、2
不会输出 3
```

---

# 3. `for` 的三个部分分别做什么

## 初始化：只执行一次

```cpp
int i = 0
```

只会在循环开始之前运行一次。

通常负责：

* 创建计数器
* 设置计数器初始值

例如：

```cpp
for (int i = 1; ...; ...) {
}
```

表示从 `1` 开始计数。

---

## 条件：每轮开始之前检查

```cpp
i < 3
```

每次准备进入循环体之前都会检查。

如果为：

```cpp
true
```

则执行循环体。

如果为：

```cpp
false
```

循环立刻结束。

因此：

```cpp
for (int i = 0; i < 3; i++)
```

中的 `i < 3` 与下面的 `while` 条件作用相同：

```cpp
int i = 0;

while (i < 3) {
    ...
}
```

---

## 更新：每轮循环体执行完之后运行

```cpp
i++
```

表示：

```cpp
i = i + 1;
```

因此每完成一轮，`i` 增加 1。

例如：

```text
0 → 1 → 2 → 3
```

然后下一轮再重新检查条件。

---

# 4. `for` 循环和 `while` 循环的对应关系

下面这个 `for`：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

基本等价于：

```cpp
int i = 0;

while (i < 3) {
    std::cout << i;
    i++;
}
```

也就是说，`for` 循环只是把：

```text
初始化
条件
更新
```

集中写在了一行里。

因此非常适合：

> 已知循环次数，或者使用一个规则变化的计数器进行循环。

例如：

```cpp
for (int i = 1; i <= 10; i++) {
}
```

表达的意思非常直观：

> 让 `i` 从 1 数到 10。

---

# 5. 为什么第一次循环看到的是 `0`，而不是 `1`

看：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

很多初学者可能错误理解成：

```text
先执行 i++
然后进入循环体
```

实际上不是。

正确顺序是：

```text
检查条件
↓
执行 body
↓
执行 i++
```

因此第一轮：

```cpp
i = 0
```

先执行：

```cpp
std::cout << i;
```

输出：

```text
0
```

之后才：

```cpp
i++;
```

变成：

```text
1
```

---

# 6. 为什么不会输出 `3`

因为条件是：

```cpp
i < 3
```

当：

```cpp
i == 3
```

时：

```cpp
3 < 3
```

结果为：

```cpp
false
```

所以循环体不会执行。

因此：

```cpp
for (int i = 0; i < 3; i++)
```

产生的是：

```text
0, 1, 2
```

而不是：

```text
0, 1, 2, 3
```

---

# 7. `<` 和 `<=` 决定终点是否包含

这是写循环时非常重要的一点。

## 不包含终点

```cpp
for (int i = 1; i < n; i++)
```

计数：

```text
1, 2, 3, ..., n-1
```

不包含 `n`。

---

## 包含终点

```cpp
for (int i = 1; i <= n; i++)
```

计数：

```text
1, 2, 3, ..., n
```

包含 `n`。

例如：

```cpp
for (int i = 1; i <= 4; i++) {
}
```

循环体会执行：

```text
i = 1
i = 2
i = 3
i = 4
```

---

# 8. `i++` 和 `++i`

C++ 中：

```cpp
i++;
```

和：

```cpp
++i;
```

都可以让：

```cpp
i
```

增加 `1`。

所以作为 `for` 循环的更新部分：

```cpp
for (...; ...; i++)
```

和：

```cpp
for (...; ...; ++i)
```

对于这种简单计数循环来说，效果相同。

例如：

```cpp
for (int i = 0; i < 3; i++) {
}
```

和：

```cpp
for (int i = 0; i < 3; ++i) {
}
```

都会让：

```text
i = 0 → 1 → 2
```

以后需要注意的是，`i++` 和 `++i` 在“表达式的返回值”上存在区别，但如果这里只是单纯让计数器加 1，则不需要过度纠结。

---

# 9. 不要在循环体中再次修改计数器

假设已经写了：

```cpp
for (int i = 1; i <= n; i++) {
}
```

那么每轮结束时 `for` 已经自动执行：

```cpp
i++;
```

不要再在循环体中写：

```cpp
for (int i = 1; i <= n; i++) {
    i++;
}
```

因为这样每轮 `i` 实际会增加两次。

例如：

```text
i = 1

循环体中的 i++
→ i = 2

for 头部中的 i++
→ i = 3
```

下一轮直接从：

```text
3
```

开始。

于是：

```text
2
```

被跳过。

整个计数可能变成：

```text
1, 3, 5, 7, ...
```

而不是：

```text
1, 2, 3, 4, 5, ...
```

因此一般原则是：

> 如果计数器已经在 `for` 的更新部分进行修改，就不要在循环体里再重复修改它。

# 10. `for` 循环中的变量作用域

考虑：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

这里：

```cpp
int i = 0
```

是在 `for` 循环中声明的。

因此 `i` 的作用域属于这个循环。

可以在循环体中使用：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;  // OK
}
```

但是循环结束后：

```cpp
for (int i = 0; i < 3; i++) {
}

std::cout << i;
```

这里的：

```cpp
i
```

已经不存在了，因此会产生编译错误。

可以简单理解成：

```text
进入循环
→ 创建 i

循环结束
→ 销毁 i
```

---

# 11. 什么变量应该声明在循环外面

如果一个变量在循环结束之后仍然需要使用，那么它通常应该声明在循环之外。

最常见的例子就是：

> accumulator（累加器）

例如：

```cpp
int total = 0;

for (int i = 1; i <= 3; i++) {
    total += i;
}

return total;
```

这里：

```cpp
total
```

必须声明在循环外面，因为：

1. 每一轮都需要保留上一轮累计的结果
2. 循环结束之后还需要 `return total`

---

# 12. 累加器 accumulator

例如我们想计算：

```text
1 + 2 + 3
```

可以写：

```cpp
int total = 0;

for (int i = 1; i <= 3; i++) {
    total += i;
}
```

其中：

```cpp
total += i;
```

等价于：

```cpp
total = total + i;
```

执行过程：

```text
开始：

total = 0

i = 1
total = 0 + 1 = 1

i = 2
total = 1 + 2 = 3

i = 3
total = 3 + 3 = 6
```

最终：

```text
total = 6
```

这种不断把结果加进同一个变量的变量叫：

> accumulator（累加器）

---

# 13. 为什么累加器通常从 `0` 开始

如果做的是加法：

```cpp
int total = 0;
```

因为 `0` 是加法的单位元：

```text
0 + x = x
```

例如第一次：

```cpp
total += 1;
```

就是：

```cpp
0 + 1
```

如果一次循环都没有执行：

```cpp
int total = 0;

for (...) {
}
```

那么最终结果仍然是：

```text
0
```

这通常也是“没有任何元素可以相加”时合理的结果。

---

# 14. 求平方和的思路

例如想计算：

```text
1² + 2² + 3² + 4²
```

也就是：

```text
1 + 4 + 9 + 16
```

结果：

```text
30
```

我们需要：

1. `i` 从 `1` 开始
2. 一直循环到 `n`
3. 每轮计算 `i * i`
4. 把平方加入 `total`

因此核心结构是：

```cpp
int total = 0;

for (int i = 1; i <= n; i++) {
    total += i * i;
}
```

注意：

```cpp
i <= n
```

而不是：

```cpp
i < n
```

因为题目要求包括最后的 `n²`。

---

# 15. 为什么 `n <= 0` 时自然得到 `0`

假设：

```cpp
n = 0
```

循环：

```cpp
for (int i = 1; i <= n; i++)
```

第一次检查：

```cpp
1 <= 0
```

结果：

```text
false
```

因此循环一次都不会执行。

`total` 保持：

```cpp
0
```

最后返回：

```cpp
return total;
```

于是结果为：

```text
0
```

如果：

```cpp
n = -5
```

第一次检查：

```cpp
1 <= -5
```

同样为：

```text
false
```

所以依然返回：

```text
0
```

这说明有时并不需要专门写：

```cpp
if (n <= 0) {
    return 0;
}
```

因为正确设计循环条件之后，这个情况本身就会被自然处理。

# 16. `for` 循环的经典写法模板

## 从 `0` 数到 `n - 1`

```cpp
for (int i = 0; i < n; i++) {
    // 使用 i
}
```

访问：

```text
0, 1, 2, ..., n-1
```

这在数组和容器索引中尤其常见。

---

## 从 `1` 数到 `n`

```cpp
for (int i = 1; i <= n; i++) {
    // 使用 i
}
```

访问：

```text
1, 2, 3, ..., n
```

---

## 倒着数

```cpp
for (int i = n; i >= 1; i--) {
}
```

访问：

```text
n, n-1, n-2, ..., 1
```

---

## 每次增加 2

```cpp
for (int i = 0; i <= n; i += 2) {
}
```

访问：

```text
0, 2, 4, 6, ...
```

# 17. 一个非常实用的循环分析方法

看到：

```cpp
for (int i = 1; i <= n; i++) {
    total += i * i;
}
```

可以按照下面 4 个问题检查：

### ① 从哪里开始？

```cpp
int i = 1
```

所以：

```text
从 1 开始
```

### ② 什么时候继续？

```cpp
i <= n
```

所以：

```text
只要 i 不超过 n 就继续
```

### ③ 每次怎么变化？

```cpp
i++
```

所以：

```text
每轮增加 1
```

### ④ 每轮做什么？

```cpp
total += i * i;
```

所以：

```text
把当前 i 的平方加入总和
```

组合起来就是：

> 从 1 开始，每次增加 1，一直到 n，并把每个整数的平方加入总和。

# 18. 常见错误总结

## 错误 1：边界少了一项

错误：

```cpp
for (int i = 1; i < n; i++)
```

如果题目要求：

```text
1 到 n，包括 n
```

应该写：

```cpp
for (int i = 1; i <= n; i++)
```

---

## 错误 2：循环体中重复 `i++`

错误：

```cpp
for (int i = 1; i <= n; i++) {
    total += i * i;
    i++;
}
```

因为计数器每轮被增加两次，会跳过数字。

---

## 错误 3：把累加器声明在循环里面

错误：

```cpp
for (int i = 1; i <= n; i++) {
    int total = 0;
    total += i * i;
}
```

每轮都会重新创建：

```cpp
total = 0
```

之前累积的数据会被丢掉。

正确：

```cpp
int total = 0;

for (int i = 1; i <= n; i++) {
    total += i * i;
}
```

---

## 错误 4：循环结束后访问 `i`

错误：

```cpp
for (int i = 0; i < 3; i++) {
}

std::cout << i;
```

因为 `i` 已经超出作用域。

---

# 19. 核心知识总结

可以把 `for` 循环记成：

```cpp
for (起点; 是否继续; 每轮如何变化) {
    每轮要做的事情
}
```

例如：

```cpp
for (int i = 1; i <= n; i++) {
    total += i * i;
}
```

意思就是：

```text
起点：
i = 1

条件：
i <= n

变化：
i 每轮 +1

任务：
把 i² 加入 total
```

最重要的几个知识点：

```text
for 的执行顺序：
初始化 → 条件 → body → 更新 → 条件 → body → 更新 → ...

初始化只执行一次

条件在每轮 body 之前检查

更新在每轮 body 之后执行

i < n  通常不包含 n
i <= n 包含 n

在 for 初始化部分声明的 i
通常只能在这个循环内部使用

需要跨越多轮保存状态的累加器
应该声明在循环外

不要同时在 for 更新部分和循环体中修改同一个计数器
```
