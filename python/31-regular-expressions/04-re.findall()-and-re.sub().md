### 使用 `re.findall()` 和 `re.sub()` 查找与替换

Python 的 `re` 模块中两个最强大的工具是用于从字符串中提取所有匹配项的 `re.findall()`，以及用于执行基于模式替换的 `re.sub()`。它们结合在一起，可以处理绝大多数实际的文本处理任务，从日志中抓取数据到清理用户输入等等。

### 它们的工作原理

**`re.findall(pattern, string)`** 会扫描整个字符串并返回所有非重叠匹配项的列表。如果模式中包含捕获组，它将返回捕获组的内容而不是完整匹配项。如果存在多个捕获组，则每个匹配项都会成为一个元组。

**`re.sub(pattern, replacement, string)`** 会找到模式的所有出现位置并进行替换。替换内容可以是一个普通字符串，可以通过 `\1`、`\2` 等引用捕获组，甚至可以是一个**可调用对象**（callable，即函数），该函数接收每个匹配对象并返回替换字符串。

### 语法

```python
import re

# Find all matches
matches = re.findall(pattern, string, flags=0)

# Replace all matches with a string
result = re.sub(pattern, replacement_string, string, count=0, flags=0)

# Replace all matches using a function
result = re.sub(pattern, replacement_function, string, count=0, flags=0)
```

### 示例

```python
import re

# findall: extract all email addresses from text
text = "Contact alice@mail.com or bob@work.org for details."
emails = re.findall(r'[\w.]+@[\w.]+', text)
# emails -> ['alice@mail.com', 'bob@work.org']

# findall with groups: extract area codes from phone numbers
phones = "Call (212) 555-1234 or (415) 555-6789"
codes = re.findall(r'\((\d{3})\)', phones)
# codes -> ['212', '415']  (only the captured group content)

# sub: replace dates from MM/DD/YYYY to YYYY-MM-DD
log = "Event on 03/15/2024 and 11/02/2023"
result = re.sub(r'(\d{2})/(\d{2})/(\d{4})', r'\3-\1-\2', log)
# result -> 'Event on 2024-03-15 and 2023-11-02'

# sub with a callable: uppercase every word starting with 'a'
sentence = "an apple a day keeps ailments away"
result = re.sub(r'\ba\w*', lambda m: m.group().upper(), sentence)
# result -> 'AN APPLE A DAY keeps AILMENTS AWAY'
```

### 核心概念

- **`re.IGNORECASE`（或 `re.I`）**：使模式匹配不区分大小写，因此 `r'hello'` 可以匹配 `"Hello"`、`"HELLO"` 等。
- **`re.escape(string)`**：转义字符串中的正则表达式特殊字符，使其可以安全地用作字面量模式。在根据用户提供的输入构建模式时至关重要。
- **单词边界 `\b`**：匹配单词字符与非单词字符之间的边界。使用它们可以仅匹配完整单词。`r'\bcat\b'` 会匹配 `"cat"`，但不会匹配 `"category"`。
- **可调用对象替换**：当 `re.sub()` 的第二个参数是一个函数时，它会为每次匹配接收一个 `Match` 对象。你可以检查该匹配（例如 `m.group()`、`len(m.group())`）来计算动态替换内容。
- **分支选择 `|`**：在模式中，`a|b|c` 匹配任意一个备选项。与分组结合使用时，`(word1|word2|word3)` 可以匹配这些单词中的任意一个。

### 构建动态模式

当你需要匹配多个字面量字符串中的某一个时，可以在分组内使用 `|` 将它们连接起来：

```python
fruits = ["apple", "banana", "cherry"]
pattern = r'\b(' + '|'.join(re.escape(f) for f in fruits) + r')\b'
# pattern -> r'\b(apple|banana|cherry)\b'
```

这将创建一个正则表达式，以完整单词的形式匹配其中任意一个词。
