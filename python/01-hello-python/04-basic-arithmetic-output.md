# Python：在 `print()` 中进行算术运算

## 1. 核心概念

Python 的 `print()` 不只能输出文字，也可以直接输出**表达式计算后的结果**。

例如：

```python
print(3 + 4)
```

Python 会先计算：

```text
3 + 4 = 7
```

然后输出：

```text
7
```

执行顺序可以理解为：

```text
计算表达式 → 得到结果 → print() 输出结果
```

---

## 2. 有引号和没有引号的区别

这是最重要的区别之一。

### 有引号：当作字符串输出

```python
print("8 + 2")
```

输出：

```text
8 + 2
```

因为 `"8 + 2"` 是一个字符串（string），Python 不会计算里面的数学表达式。

### 没有引号：执行算术运算

```python
print(8 + 2)
```

输出：

```text
10
```

Python 把 `8 + 2` 看作一个数学表达式，所以会先计算，再输出结果。

可以记成：

```text
"8 + 2"  → 文本
8 + 2    → 数学表达式
```

---

## 3. 四个基本算术运算符

| 运算符 | 含义 | 示例       |    结果 |
| --- | -- | -------- | ----: |
| `+` | 加法 | `5 + 3`  |   `8` |
| `-` | 减法 | `20 - 6` |  `14` |
| `*` | 乘法 | `4 * 9`  |  `36` |
| `/` | 除法 | `18 / 3` | `6.0` |

示例：

```python
print(10 + 5)
print(50 - 22)
print(6 * 7)
print(20 / 4)
```

输出：

```text
15
28
42
5.0
```

---

## 4. 为什么除法输出 `5.0` 而不是 `5`

Python 中使用 `/` 进行除法时，结果总是 `float`（浮点数）。

```python
print(20 / 4)
```

输出：

```text
5.0
```

虽然数学上结果是整数 `5`，但 Python 仍然返回：

```python
5.0
```

类型是：

```python
float
```

例如：

```python
print(45 / 5)
```

输出：

```text
9.0
```

因此要记住：

> Python 的 `/` 是普通除法，结果始终是浮点数。

---

## 5. 减法中的顺序非常重要

表达式：

```python
100 - 36
```

表示：

> 从 `100` 中减去 `36`

结果：

```text
64
```

英文中的：

> subtract 36 from 100

应该理解成：

```python
100 - 36
```

而不是：

```python
36 - 100
```

因为：

```text
subtract A from B
```

对应：

```text
B - A
```

---

## 6. 直接在 `print()` 中写表达式

如果题目要求使用运算符直接计算，推荐写成：

```python
print(15 + 27)
print(100 - 36)
print(7 * 8)
print(45 / 5)
```

不要先手动算出结果，再写成：

```python
print(42)
print(64)
print(56)
print(9.0)
```

虽然输出相同，但后者没有真正练习算术表达式。

更不要写成字符串：

```python
print("15 + 27")
```

因为这只会输出：

```text
15 + 27
```

而不会得到 `42`。

---

## 7. 放进函数中

如果题目要求：

```python
def solve():
```

就需要把程序放进 `solve()` 函数：

```python
def solve():
    print(15 + 27)
    print(100 - 36)
    print(7 * 8)
    print(45 / 5)
```

如果需要直接运行这个 Python 文件，通常还可以调用：

```python
def solve():
    print(15 + 27)
    print(100 - 36)
    print(7 * 8)
    print(45 / 5)


solve()
```

执行后输出：

```text
42
64
56
9.0
```

---

## 8. 常见错误

### 错误 1：给表达式加引号

```python
print("15 + 27")
```

输出：

```text
15 + 27
```

正确：

```python
print(15 + 27)
```

输出：

```text
42
```

### 错误 2：减法顺序写反

题目：

```text
subtract 36 from 100
```

正确：

```python
print(100 - 36)
```

错误：

```python
print(36 - 100)
```

### 错误 3：认为 `/` 会输出整数

```python
print(45 / 5)
```

输出是：

```text
9.0
```

不是：

```text
9
```

### 错误 4：把答案直接写死

```python
print(42)
```

虽然输出正确，但如果题目要求使用算术运算符，就应该写：

```python
print(15 + 27)
```

---

## 9. 核心总结

```python
print(3 + 4)
```

表示：

> 先计算 `3 + 4`，再输出 `7`。

而：

```python
print("3 + 4")
```

表示：

> 直接输出文字 `3 + 4`。

四个基本运算符：

```text
+   加法
-   减法
*   乘法
/   除法
```

其中需要特别记住：

```text
/ 的结果总是 float
```

例如：

```python
print(45 / 5)
```

输出：

```text
9.0
```

# 练习题解答：在 `print()` 中完成四个算术运算

## 问题

编写一个 `solve()` 函数，依次输出四行：

1. `15` 加 `27`
2. `100` 减 `36`
3. `7` 乘 `8`
4. `45` 除以 `5`

要求直接在 `print()` 中使用算术运算符，不要把计算结果写死。

期望输出：

```text
42
64
56
9.0
```

## 答案

```python
def solve():
    print(15 + 27)
    print(100 - 36)
    print(7 * 8)
    print(45 / 5)
```

如果需要直接运行这个文件，可以再调用：

```python
def solve():
    print(15 + 27)
    print(100 - 36)
    print(7 * 8)
    print(45 / 5)


solve()
```

## 为什么这样写

第一行：

```python
print(15 + 27)
```

Python 先计算：

```text
15 + 27 = 42
```

第二行：

```python
print(100 - 36)
```

Python 计算：

```text
100 - 36 = 64
```

第三行：

```python
print(7 * 8)
```

Python 计算：

```text
7 × 8 = 56
```

第四行：

```python
print(45 / 5)
```

Python 计算：

```text
45 ÷ 5 = 9.0
```

这里输出 `9.0`，因为 Python 的 `/` 除法运算符总是返回浮点数。

最终输出：

```text
42
64
56
9.0
```
