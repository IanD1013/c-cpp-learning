# 在终端中编辑文件：`nano` 与 `vi`

## 1. 为什么需要终端编辑器

之前使用：

```bash
cat file
```

只能**查看文件内容**。

如果要直接在终端里修改已有文件，可以使用终端文本编辑器，例如：

* `nano`：操作直观，类似普通记事本
* `vi`：基于“模式”操作，功能更强，但学习成本更高

例如，要修改：

```text
/home/learner/lab/course-app.conf
```

原内容：

```text
HOST=127.0.0.1
PORT=8080
```

目标是只把端口改为：

```text
HOST=127.0.0.1
PORT=8081
```

---

## 2. 使用 `nano`

打开文件：

```bash
nano /home/learner/lab/course-app.conf
```

`nano` 中可以直接移动光标并输入文字，没有额外的“编辑模式”。

将：

```text
PORT=8080
```

改成：

```text
PORT=8081
```

然后：

```text
Ctrl-O
```

表示 **Write Out（写入文件）**，即保存。

`nano` 会要求确认文件名，此时按：

```text
Enter
```

最后：

```text
Ctrl-X
```

退出 `nano`。

### 常用快捷键

| 操作      | 快捷键      |
| ------- | -------- |
| 保存      | `Ctrl-O` |
| 确认保存文件名 | `Enter`  |
| 退出      | `Ctrl-X` |

可以记成：

```text
编辑 → Ctrl-O → Enter → Ctrl-X
```

---

## 3. 使用 `vi`

打开文件：

```bash
vi /home/learner/lab/course-app.conf
```

### `vi` 最重要的概念：模式

`vi` 是 **modal editor（模式编辑器）**。

也就是说：

> 同一个按键在不同模式下具有完全不同的作用。

最基本的两个模式是：

### 命令模式

刚打开 `vi` 时默认处于命令模式。

此时直接按字母通常**不是输入文字**，而是在执行编辑命令。

### 插入模式

按：

```text
i
```

进入 Insert Mode（插入模式）。

这时就可以像普通编辑器一样输入文字。

---

## 4. `vi` 的基本编辑流程

打开：

```bash
vi /home/learner/lab/course-app.conf
```

移动光标到：

```text
PORT=8080
```

按：

```text
i
```

进入插入模式，然后把 `8080` 修改成 `8081`。

编辑完成后按：

```text
Esc
```

返回命令模式。

然后输入：

```vim
:wq
```

再按 Enter。

其中：

* `w` = write，保存
* `q` = quit，退出

因此：

```vim
:wq
```

就是：

> 保存并退出。

基本流程：

```text
打开文件
   ↓
移动光标
   ↓
i
   ↓
编辑
   ↓
Esc
   ↓
:wq
   ↓
Enter
```

---

## 5. 不保存并退出 `vi`

如果修改错了，不想保存，可以：

```text
Esc
```

然后输入：

```vim
:q!
```

按 Enter。

含义：

* `q`：quit
* `!`：强制执行

所以：

```vim
:q!
```

表示：

> 放弃所有未保存修改并退出。

这是使用 `vi` 时非常重要的“逃生命令”。

---

## 6. `vi` 中的 `:` 命令

在命令模式下输入：

```text
:
```

可以执行针对文件的 Ex 命令。

常见的有：

```vim
:w
```

保存文件。

```vim
:q
```

退出。

```vim
:wq
```

保存并退出。

```vim
:q!
```

不保存，强制退出。

这些操作针对的是**整个文件或编辑器状态**，而不是在光标位置输入普通文字。

---

## 7. 使用 `vi` 全局替换文本

`vi` 可以直接搜索并替换文件中的内容。

例如：

```vim
:%s/8080/8081/
```

含义可以拆开理解：

```text
:      进入命令
%      整个文件
s      substitute，替换
8080   要查找的内容
8081   替换后的内容
```

因此：

```vim
:%s/8080/8081/
```

表示：

> 在整个文件中，把每一行首次出现的 `8080` 替换为 `8081`。

如果要把每一行中的**所有匹配项**都替换，通常使用：

```vim
:%s/8080/8081/g
```

这里：

```text
g = global
```

表示一行中有多个匹配时也全部替换。

### 注意

全局替换非常方便，但要先确认文件中是否存在其他不应该修改的 `8080`。

如果只需要修改一个明确位置，直接移动光标编辑通常更安全。

---

## 8. 修改后验证文件

编辑文件以后，不要只相信“自己应该已经保存了”，最好重新查看文件：

```bash
cat /home/learner/lab/course-app.conf
```

正确结果应该是：

```text
HOST=127.0.0.1
PORT=8081
```

这是一种很重要的命令行习惯：

```text
修改 → 保存 → 重新读取 → 验证
```

---

## 9. 注意文件末尾的换行符

这个文件要求：

```text
HOST=127.0.0.1\n
PORT=8081\n
```

也就是说，**最后一行后面也应该有换行符**。

正常使用 `nano` 或 `vi` 编辑并保存时，一般会正确处理文本文件末尾的换行。

不要误把文件变成：

```text
HOST=127.0.0.1PORT=8081
```

因为这已经变成了一行。

理想结构始终是：

```text
HOST=127.0.0.1
PORT=8081
```

## 11. 核心记忆

### `nano`

```text
直接编辑
Ctrl-O → 保存
Enter  → 确认
Ctrl-X → 退出
```

### `vi`

```text
i     → 开始输入
Esc   → 回到命令模式
:wq   → 保存并退出
:q!   → 放弃修改并退出
```

### 最重要的区别

| `nano`      | `vi`      |
| ----------- | --------- |
| 类似普通记事本     | 模式编辑器     |
| 打开后直接输入     | 必须先进入插入模式 |
| 上手简单        | 学习成本较高    |
| `Ctrl-O` 保存 | `:w` 保存   |
| `Ctrl-X` 退出 | `:q` 退出   |

对于简单修改，`nano` 通常更容易上手；但 `vi` 几乎存在于所有 Unix/Linux 环境中，因此至少应该掌握：

```text
i
Esc
:wq
:q!
```

这四个操作。
